# PachaQ’ipi

Sitio web modular de preparación familiar ante sismos. La portada de index.html abre el acceso ubicado en pages/login.html.

## Organización

- pages/: una página HTML para cada sección y flujo de la interfaz.
- css/: estilos separados para la base visual, componentes, páginas, panel, acceso y tamaños de pantalla.
- js/: inicio de la aplicación y módulos de estado, navegación, formularios, interacciones y avisos.
- assets/images/: reservado para fotografías, ilustraciones y mapas.
- assets/icons/: reservado para iconos en archivos SVG.
- assets/fonts/: reservado para fuentes tipográficas.
- assets/videos/: reservado para videos de apoyo.

Las carpetas de assets están vacías. Los comentarios en las páginas y estilos indican nombres sugeridos y el lugar de cada recurso futuro.

## Interacciones de demostración

Los formularios, preferencias, integrantes, insumos, zonas y respuestas del simulacro se guardan en el almacenamiento local del navegador. No hay servicios de autenticación, sincronización ni emergencia conectados.

Sirve el proyecto desde la carpeta raíz con un servidor web local para que el navegador pueda cargar los módulos JavaScript.
